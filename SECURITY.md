# Politique de sécurité / Política de seguridad

*(Français — voir note en bas de page pour l'espagnol)*

## Portée

Ce dépôt est un **laboratoire personnel et une vitrine de démonstration**
(scripts, documentation) autour des migrations VMware → Proxmox, publié par
**Intermovil TEC**. Ce n'est **pas un logiciel de production** ni un service
exposé publiquement : il n'y a donc pas d'engagement de niveau de service
(SLA) sur le traitement des rapports de sécurité.

## Signaler un problème de sécurité

Si vous découvrez une vulnérabilité, une fuite potentielle de secret, ou un
problème de sécurité sensible dans ce dépôt (par exemple dans un script ou un
exemple de configuration) :

- **Merci de ne pas ouvrir d'issue publique** pour un signalement sensible.
- Contactez l'auteur directement à l'adresse : **[email professionnel]**
  (à confirmer — voir le `README.md` pour les coordonnées à jour).
- Décrivez le problème aussi précisément que possible : fichier concerné,
  étapes de reproduction, impact potentiel.

## À quoi s'attendre

- Ce dépôt est maintenu sur une base **best effort**, en dehors d'un cadre
  commercial formel. Les rapports seront examinés dès que possible, sans
  garantie de délai de réponse.
- Aucune donnée sensible réelle (mots de passe, clés, adresses IP de
  production) ne doit être présente dans ce dépôt ; si vous en trouvez,
  merci de le signaler en priorité.
